# Personnaliser le projet

- textes : **MODELE_POSTE/index.html** ;
- apparence : **MODELE_POSTE/assets/style.css** ;
- logique et phrase de frappe : **MODELE_POSTE/assets/jeu.js** ;

**POSTES_GENERES**, car ce dossier est remplacé.
