# Publication sur GitHub

Avant la publication, vérifiez que **POSTES_GENERES** et **reponses.txt** sont
ignorés et qu’aucun nom d’élève n’est présent.

Commandes :

~~~powershell
git init
git branch -M main
git add .
git commit -m "Publication initiale de Mission Code Secret"
git remote add origin https://github.com/VOTRE-COMPTE/mission-code-secret-tc.git
git push -u origin main
~~~
